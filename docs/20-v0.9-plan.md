# 0.9: add your own games (beta)

## What was asked, and what was decided
First idea: a button under the games that lets you choose the game's file system, and then "make it like Mod Organizer 2". After looking at what MO2 really does, the decision is a smaller thing that fits this app: **not MO2**. MO2 is built for Bethesda games and depends on a native component; this app is for Paradox games and Bannerlord. So 0.9 is:

- **"＋ Add a game (beta)"** at the end of the game list: define a game yourself, no code and no new release needed, for games that work like the Paradox ones (a mod list file in Documents) or like Bannerlord (module folders, game started with the list).
- **"Check this game (beta)"** in Settings -> Game, for every game: the debug view that says what was found and what was looked for.
- Everything is labelled beta. Games you add are never marked verified.

## How it works
A game is only data (`modmanager/games.py`, `Game`): the engine has no per-game code. `modmanager/customgames.py` turns the form into that data:

| Field | Meaning |
|---|---|
| name, Steam app id | list entry; used for `steam://run/<id>` and the Workshop folder `steamapps/workshop/content/<id>` |
| folder in Documents (+ parent) | the game's user folder (`Documents/<parent>/<folder>`); you can also set the user folder by path under Settings -> Storage |
| install folder name, "folder that proves it is the game" | how an install is found and recognised when you paste any path inside it |
| base content folder | where the game's own files are inside the install (`game` for most Paradox games, empty for Stellaris, `Modules` for Bannerlord) |
| mod list file, how mods are listed | `dlc_load.json`; `descriptor` (`mod/ugc_<id>.mod`) or `path` |
| folders to check for conflicts, base game folders to compare | script folders where two mods can clash |
| Bannerlord style: starting modules, executable, arguments | how the game is started with the module list |
| accent colour | the theme is made from it |

Safety: every name is a plain folder name (no `..`, drive letters or slashes beyond the marker path); at most 20 added games; the list lives in `custom_games.json` in the app's data folder; a broken entry is skipped, never fatal; "Erase all data" removes added games too. Removing a game only forgets the definition (its playsets stay unless you choose to erase them); the game's own files are never touched.

Templates (Stellaris, Imperator: Rome) are **from memory of other mod managers and not checked on a real install**; the form says so. Anyone who tries one: use "Check this game" and correct the field it points at.

## Is this "fine for now" for future games?
Yes. Adding a Paradox-style game no longer needs a code change: fill the form. A code change is only needed when a game works differently (a new `kind`, like Civilization VI's `.modinfo` mods; see docs/18).

## Looked at and left out
- **Mod Organizer 2 style virtual file system.** MO2 injects a native DLL (USVFS) into the game so it sees all mods merged. Windows does not require that DLL to be signed, but Smart App Control and antivirus block unsigned injected code, and it needs native C++ code, not stdlib Python. Not done.
- **Deploying files into the game folder** (hard links or copies, like Vortex). Real risks: a game that rewrites a linked file also changes the mod's original; a crash leaves links behind; Steam launches games through a stub so "when did the game end" is unknown; copies double the disk space. Not needed for Paradox games or Bannerlord, which load mods from folders.
- **Windows Projected File System** (a built-in virtual folder): possible through `ctypes`, but needs an optional Windows feature (admin to enable) and could not be tested here. A future research spike if a game ever needs it.
- **Python edition** (a `.pyz` run by the signed `py.exe`, no exe of ours, tiny on disk): useful because files cannot be signed and Smart App Control blocks unsigned exes. Not part of 0.9; ready to plan when wanted.
- **Nexus downloads, profiles with their own saves, running other tools**: not for Paradox games.
